## Sitemap Submission

1. Deploy production changes.
2. Verify `https://www.code2crest.com/robots.txt`.
3. Verify `https://www.code2crest.com/sitemap.xml`.
4. Submit the sitemap in Google Search Console.
5. Resubmit after adding substantial new service, product, case study, or location pages.

## Search Console Checklist

- Verify `www.code2crest.com` as the canonical public property.
- Submit sitemap.
- Inspect homepage and `/products`.
- Confirm auth and Hub URLs are noindex.
- Monitor indexing, coverage, Core Web Vitals, and search queries.
- Add Google Business Profile website link after profile verification.

- Local Erode business associations

Avoid:
- Paid bulk backlinks
- Automated directory submissions
- Comment spam
- Forum profile spam
- PBNs
- Keyword-stuffed footer links
- Large-scale link exchanges
- Fake reviews
